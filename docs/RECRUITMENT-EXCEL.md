# 徵人 Excel 匯入

本次指定範圍為民國115年7月1日起（西元2026-07-01），截止日預設今天。

1. 更新NAS後，進入「徵人」。
2. 在「匯入Excel應徵資料」確認開始日、截止日。
3. 按「選擇Excel／整理檔」，選原本的 `.xlsx`、`.xls`，或已整理好的徵人 `.json`。
4. 預覽會顯示來源列數、依姓名與電話合併的人數、新增與略過的來源列數，以及前20列資料。
5. 按「確認匯入」，才會寫入NAS。預覽不會修改資料。

整理檔已包含日期範圍，依整理檔內設定匯入。Excel則依頁面日期範圍讀取。

## 日期與紀錄

- 單一日期分頁或有明確日期欄位的資料，保留實際日期；未填撥打時間時，不會補成午夜。
- 「115年7月2日8日」等跨多天分頁，若每列沒有日期，保留原分頁名稱及範圍，不指定某一天。可在每日紀錄的篩選選擇「日期未明」查詢。
- 只列姓名電話、沒有撥打時間、聯絡備註或面試安排的來源列，只建立應徵者，不假設已經打過電話。
- 原面試時間只是來源資料，不會憑此建立「已面試」紀錄。後續實際面試請另外新增紀錄。
- 性別、年齡、再次撥打及面試時間等原資料保留於歷史紀錄或應徵者備註；年齡維持原檔記載，不推算生日。
- 無法判定日期或日期超出匯入範圍的列會略過並顯示提醒。跨越範圍邊界、且無法拆分實際日期的分頁也不會任意切分。

## 重複與人工更改

- 以姓名＋電話數字合併人員，不只靠姓名。沒有電話時不自動與同名者合併。
- 同一姓名電話若在系統已有多份人工建立的應徵資料，匯入會停止並提示先核對，不會任意挑一份。
- 同一來源分頁、來源列及相同內容重複匯入會略過；修改來源內容後再匯入，會保留為新的來源紀錄。
- 已人工編輯的應徵者資料、電話或面試後續進度，以及已報到轉員工者，不會被Excel匯入覆蓋。
- 兩筆內容不同的聯絡紀錄會保留。不同來源分頁不能確認為同一筆時，不會直接刪掉其中一筆。

所有原始人員檔案及整理檔僅供匯入NAS，不放進GitHub。此功能不處理特休給假或覆蓋員工到職日。
